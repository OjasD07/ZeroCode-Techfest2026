# SPLITZZ! - Group Bill Splitter

SPLITZZ! is a standalone bill-splitting app built for the ZeroCode Challenge at Techfest 2026. It calculates what each person owes, tracks payment status, and produces a shareable or printable receipt. The app uses vanilla HTML, CSS, and JavaScript and does not load external libraries or services.

## Run the app

Visit the hosted app at [https://splitzz.ojasdeshpande.in/](https://splitzz.ojasdeshpande.in/), or open `ZC-1D2BABEF545A_index.html` directly in a modern browser. No build step, server, installation, or internet connection is required for the core features.

## Features

- Split a bill equally, or assign each person a custom amount or percentage.
- Add tax and a percentage-based or fixed tip; mark the subtotal as tax-inclusive.
- Reconcile individual shares to the grand total, including cent-level rounding.
- Choose from multiple currencies and occasion presets; add an event date and location.
- Track who has paid and see the collection progress.
- Copy the breakdown, print a receipt, and retain the current split in browser storage across reloads.
- Request device coordinates for the location field when the browser supports geolocation and grants permission.
- Use responsive layouts and input validation for common invalid or incomplete values.
